패널의 열림 또는 닫힘 상태를 보조 기술에 알리는 어트리뷰트는 무엇인가요?

버튼 엘리먼트에 aria-expanded을 사용하세요. 콘텐츠 패널이 보이면 "true", 숨겨져 있으면 "false"로 설정합니다. 스크린 리더 사용자에게 중요한 상태 정보입니다.

버튼과 버튼이 제어하는 콘텐츠는 어떻게 연결하나요?

버튼에 aria-controls 어트리뷰트를 사용하고 관련 콘텐츠 패널의 id와 같은 값으로 설정하세요. 이렇게 프로그래밍 방식의 관계를 설정하면 보조 기술이 해당 콘텐츠로 바로 이동할 수 있습니다.

아코디언 버튼을 포함하는 제목 엘리먼트에는 어떤 역할을 지정해야 하나요?

버튼을 포함하는 엘리먼트에는 일반적으로 role="heading"과 적절한 aria-level을 지정해 구조를 정의해야 합니다. 그러면 아코디언 섹션이 섹션 제목으로 인식되어 사용자가 페이지 구조를 탐색할 수 있습니다.
