# CLI 레퍼런스

| 명령어                             | 별칭       | 설명                                                                                                  |
| :--------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------- |
| [`add`](cli/add)                   |            | 프로젝트에서 외부 라이브러리를 사용할 수 있도록 지원 기능을 추가합니다.                               |
| [`analytics`](cli/analytics)       |            | Angular CLI 사용 통계 수집을 설정합니다.                                                              |
| [`build`](cli/build)               | `b`        | Angular 애플리케이션이나 라이브러리를 컴파일하여 지정한 출력 경로의 dist/ 디렉터리에 저장합니다.      |
| [`cache`](cli/cache)               |            | 영구 디스크 캐시를 설정하고 캐시 통계를 조회합니다.                                                   |
| [`completion`](cli/completion)     |            | 터미널에서 Angular CLI 자동 완성 기능을 설정합니다.                                                   |
| [`config`](cli/config)             |            | 워크스페이스의 angular.json 파일에서 Angular 설정값을 조회하거나 설정합니다.                          |
| [`deploy`](cli/deploy)             |            | 지정한 프로젝트나 워크스페이스의 기본 프로젝트에 대해 배포 빌더를 실행합니다.                         |
| [`e2e`](cli/e2e)                   | `e`        | Angular 애플리케이션을 빌드하고 제공한 다음 엔드 투 엔드 테스트를 실행합니다.                         |
| [`extract-i18n`](cli/extract-i18n) |            | 소스 코드에서 i18n 메시지를 추출합니다.                                                               |
| [`generate`](cli/generate)         | `g`        | 스키매틱을 기반으로 파일을 생성하거나 수정합니다.                                                     |
| [`lint`](cli/lint)                 |            | 지정한 프로젝트 폴더의 Angular 애플리케이션 코드에 린트 도구를 실행합니다.                            |
| [`new`](cli/new)                   | `n`        | 새 Angular 워크스페이스를 생성합니다.                                                                 |
| [`run`](cli/run)                   |            | Architect 타깃을 실행합니다. 프로젝트에 정의한 사용자 정의 빌더 설정을 선택적으로 사용할 수 있습니다. |
| [`serve`](cli/serve)               | `s`, `dev` | 애플리케이션을 빌드하고 제공하며, 파일이 변경되면 다시 빌드합니다.                                    |
| [`test`](cli/test)                 | `t`        | 프로젝트의 단위 테스트를 실행합니다.                                                                  |
| [`update`](cli/update)             |            | 워크스페이스와 의존성을 업데이트합니다. [업데이트 가이드](/update-guide)를 참고하세요.                |
| [`version`](cli/version)           | `v`        | Angular CLI 버전을 출력합니다.                                                                        |
