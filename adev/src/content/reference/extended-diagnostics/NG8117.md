<!--
# Functions should be invoked in text interpolation.
-->

<a id="functions-should-be-invoked-in-text-interpolation"></a>

# 문자열 바인딩에서는 함수를 호출해야 합니다

<!--
This diagnostic detects uninvoked functions in text interpolation.
-->

이 진단은 문자열 바인딩에서 호출하지 않은 함수를 감지합니다.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

<!--
## What's wrong with that?
-->

<a id="whats-wrong-with-that"></a>

## 무엇이 문제인가요?

<!--
Functions in text interpolation should be invoked to return a value.
If the function is not invoked, it will not return any value and the interpolation will not work as expected.
-->

문자열 바인딩의 함수는 값을 반환하도록 호출해야 합니다.
함수를 호출하지 않으면 값이 반환되지 않아 문자열 바인딩이 예상대로 동작하지 않습니다.

<!--
## What should I do instead?
-->

<a id="what-should-i-do-instead"></a>

## 어떻게 해결하나요?

<!--
Ensure to invoke the function when you use it in text interpolation to return the value.
-->

문자열 바인딩에서 함수를 사용할 때는 값을 반환하도록 함수를 호출하세요.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue() }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

<!--
## Configuration requirements
-->

<a id="configuration-requirements"></a>

## 필수 설정

<!--
[`strictTemplates`](/tools/cli/template-typecheck#strict-mode) must be enabled for any extended diagnostic to emit.
`uninvokedFunctionInTextInterpolation` has no additional requirements beyond `strictTemplates`.
-->

확장 진단이 발생하려면 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)를 활성화해야 합니다.
`uninvokedFunctionInTextInterpolation`에는 `strictTemplates` 외의 추가 요구 사항이 없습니다.

<!--
## What if I can't avoid this?
-->

<a id="what-if-i-cant-avoid-this"></a>

## 이 상황을 피할 수 없다면 어떻게 하나요?

<!--
This diagnostic can be disabled by editing the project's `tsconfig.json` file:
-->

프로젝트의 `tsconfig.json` 파일을 수정하여 이 진단을 비활성화할 수 있습니다.

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedFunctionInTextInterpolation": "suppress"
      }
    }
  }
}
```
