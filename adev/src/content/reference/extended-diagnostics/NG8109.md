<!--
# Signals must be invoked in template interpolations.
-->

<a id="signals-must-be-invoked-in-template-interpolations"></a>

# 템플릿 문자열 바인딩에서는 시그널을 호출해야 합니다

<!--
This diagnostic detects uninvoked signals in template interpolations.
-->

이 진단은 템플릿 문자열 바인딩에서 호출하지 않은 시그널을 감지합니다.

```angular-ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<div>{{ mySignal }}</div>`,
})
class MyComponent {
  mySignal: Signal<number> = signal(0);
}
```

<!--
## What's wrong with that?
-->

<a id="whats-wrong-with-that"></a>

## 무엇이 문제인가요?

<!--
Angular Signals are zero-argument functions (`() => T`). When executed, they return the current value of the signal.
This means they are meant to be invoked when used in template interpolations to render their value.
-->

Angular 시그널은 인수가 없는 함수(`() => T`)입니다. 실행하면 시그널의 현재 값을 반환합니다.
따라서 템플릿 문자열 바인딩으로 시그널 값을 렌더링하려면 시그널을 호출해야 합니다.

<!--
## What should I do instead?
-->

<a id="what-should-i-do-instead"></a>

## 어떻게 해결하나요?

<!--
Ensure to invoke the signal when you use it within a template interpolation to render its value.
-->

템플릿 문자열 바인딩에서 시그널 값을 렌더링하려면 시그널을 호출하세요.

```angular-ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<div>{{ mySignal() }}</div>`,
})
class MyComponent {
  mySignal: Signal<number> = signal(0);
}
```

<!--
## Configuration requirements
-->

<a id="configuration-requirements"></a>

## 필수 설정

<!--
[`strictTemplates`](tools/cli/template-typecheck#strict-mode) must be enabled for any extended diagnostic to emit.
`interpolatedSignalNotInvoked` has no additional requirements beyond `strictTemplates`.
-->

확장 진단이 발생하려면 [`strictTemplates`](tools/cli/template-typecheck#strict-mode)를 활성화해야 합니다.
`interpolatedSignalNotInvoked`에는 `strictTemplates` 외의 추가 요구 사항이 없습니다.

<!--
## What if I can't avoid this?
-->

<a id="what-if-i-cant-avoid-this"></a>

## 이 상황을 피할 수 없다면 어떻게 하나요?

<!--
This diagnostic can be disabled by editing the project's `tsconfig.json` file:
-->

프로젝트의 `tsconfig.json` 파일을 수정하여 이 진단을 비활성화할 수 있습니다.

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "interpolatedSignalNotInvoked": "suppress"
      }
    }
  }
}
```
