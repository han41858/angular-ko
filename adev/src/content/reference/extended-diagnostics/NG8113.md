# 사용하지 않는 독립형 임포트

<!--
This diagnostic detects cases where the `imports` array of a `@Component` contains symbols that
aren't used within the template.
-->

이 진단은 `@Component`의 `imports` 배열에 템플릿에서 사용하지 않는 심벌이 포함된 경우를 감지합니다.

```typescript
@Component({
  imports: [UsedDirective, UnusedPipe],
})
class AwesomeCheckbox {}
```

<!--
## What's wrong with that?
-->

<a id="whats-wrong-with-that"></a>

## 무엇이 문제인가요?

<!--
The unused imports add unnecessary noise to your code and can increase your compilation time.
-->

사용하지 않는 임포트는 코드에 불필요한 내용을 추가하고 컴파일 시간을 늘릴 수 있습니다.

<!--
## What should I do instead?
-->

<a id="what-should-i-do-instead"></a>

## 어떻게 해결하나요?

<!--
Delete the unused import.
-->

사용하지 않는 임포트를 삭제하세요.

```typescript
@Component({
  imports: [UsedDirective],
})
class AwesomeCheckbox {}
```

<!--
## What if I can't avoid this?
-->

<a id="what-if-i-cant-avoid-this"></a>

## 이 상황을 피할 수 없다면 어떻게 하나요?

<!--
This diagnostic can be disabled by editing the project's `tsconfig.json` file:
-->

프로젝트의 `tsconfig.json` 파일을 수정하여 이 진단을 비활성화할 수 있습니다.

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedStandaloneImports": "suppress"
      }
    }
  }
}
```

<!--
See [extended diagnostic configuration](extended-diagnostics#configuration) for more info.
-->

자세한 내용은 [확장 진단 설정](extended-diagnostics#configuration)을 참고하세요.
