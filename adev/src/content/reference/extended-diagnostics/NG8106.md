<a id="suffix-not-supported"></a>

# 지원되지 않는 접미사

<!--
This diagnostic detects when the `.px`, `.%`, and `.em` suffixes are used with an attribute
binding.
-->

이 진단은 어트리뷰트 바인딩에 `.px`, `.%`, `.em` 접미사를 사용한 경우를 감지합니다.

```html
<img [attr.width.px]="5" />
```

<!--
## What's wrong with that?
-->

<a id="whats-wrong-with-that"></a>

## 무엇이 문제인가요?

<!--
These suffixes are only available for style bindings. They do not have any meaning when binding to an attribute.
-->

이러한 접미사는 스타일 바인딩에서만 사용할 수 있습니다. 어트리뷰트 바인딩에서는 의미가 없습니다.

<!--
## What should I do instead?
-->

<a id="what-should-i-do-instead"></a>

## 어떻게 해결하나요?

<!--
Rather than using the `.px`, `.%`, or `.em` suffixes that are only supported in style bindings,
move this to the value assignment of the binding.
-->

스타일 바인딩에서만 지원하는 `.px`, `.%`, `.em` 접미사를 사용하는 대신 단위를 바인딩에 할당하는 값에 포함하세요.

```html
<img [attr.width]="'5px'" />
```

<!--
## Configuration requirements
-->

<a id="configuration-requirements"></a>

## 필수 설정

<!--
[`strictTemplates`](tools/cli/template-typecheck#strict-mode) must be enabled for any extended diagnostic to emit.
`suffixNotSupported` has no additional requirements beyond `strictTemplates`.
-->

확장 진단이 발생하려면 [`strictTemplates`](tools/cli/template-typecheck#strict-mode)를 활성화해야 합니다.
`suffixNotSupported`에는 `strictTemplates` 외의 추가 요구 사항이 없습니다.

<!--
## What if I can't avoid this?
-->

<a id="what-if-i-cant-avoid-this"></a>

## 이 상황을 피할 수 없다면 어떻게 하나요?

<!--
This diagnostic can be disabled by editing the project's `tsconfig.json` file:
-->

프로젝트의 `tsconfig.json` 파일을 수정하여 이 진단을 비활성화할 수 있습니다.

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "suffixNotSupported": "suppress"
      }
    }
  }
}
```

See [extended diagnostic configuration](extended-diagnostics#configuration) for more info.
