# 숫자로 지정한 CSS 프로퍼티에는 단위가 필요합니다

<!--
This diagnostic detects when a numeric value is bound to a CSS length property that requires a CSS unit to have any effect.
-->

이 진단은 단위가 있어야 적용되는 CSS 길이 프로퍼티에 숫자 값을 바인딩한 경우를 감지합니다.

```angular-html
<!-- Binding a bare number – has no visual effect -->
<div [style.width]="500"></div>

<!-- Binding a numeric string – also has no effect -->
<div [style.padding]="'20'"></div>
```

<!--
## What's wrong with that?
-->

<a id="whats-wrong-with-that"></a>

## 무엇이 문제인가요?

<!--
CSS length properties such as `width`, `height`, `margin`, `padding`, `font-size`, and many others require a unit (e.g. `px`, `em`, `%`, `rem`) to take effect. Binding a plain number like `500` sets the property to the string `"500"`, which browsers treat as an invalid value and silently ignore. The element is rendered as if the style were never applied.
-->

`width`, `height`, `margin`, `padding`, `font-size` 등의 CSS 길이 프로퍼티는 적용되려면 `px`, `em`, `%`, `rem` 같은 단위가 필요합니다. `500`처럼 단위 없는 숫자를 바인딩하면 프로퍼티에 문자열 `"500"`이 설정됩니다. 브라우저는 이를 유효하지 않은 값으로 판단해 별도 경고 없이 무시합니다. 엘리먼트는 스타일을 적용하지 않은 것처럼 렌더링됩니다.

<!--
## What should I do instead?
-->

<a id="what-should-i-do-instead"></a>

## 대신 어떻게 해야 하나요?

<!--
There are two idiomatic ways to bind a length value with a unit in Angular templates.
-->

Angular 템플릿에서 단위가 있는 길이 값을 바인딩하는 일반적인 방법은 두 가지입니다.

<!--
### Use the unit-suffix shorthand
-->

<a id="use-the-unit-suffix-shorthand"></a>

### 단위 접미사 축약 구문 사용하기

<!--
Append the desired unit directly to the binding name using the `.unit` suffix syntax:
-->

`.unit` 접미사 구문을 사용해 원하는 단위를 바인딩 이름에 직접 붙이세요:

```angular-html
<div [style.width.px]="500"></div>
<div [style.padding.rem]="1.5"></div>
<div [style.margin-top.%]="10"></div>
```

<!--
### Bind a string that already includes the unit
-->

<a id="bind-a-string-that-already-includes-the-unit"></a>

### 단위를 포함한 문자열 바인딩하기

<!--
If you need to compose the value dynamically, bind a complete CSS value string instead:
-->

값을 동적으로 조합해야 한다면 단위까지 포함한 CSS 값 문자열을 바인딩하세요:

```angular-html
<div [style.width]="'500px'"></div>
<div [style.padding]="myPadding + 'px'"></div>
```

<!--
## Configuration requirements
-->

<a id="configuration-requirements"></a>

## 설정 요구사항

<!--
[`strictTemplates`](tools/cli/template-typecheck#strict-mode) must be enabled for any extended
diagnostic to emit.
`numericCssPropertyRequiresUnit` has no additional requirements beyond `strictTemplates`.
-->

확장 진단을 표시하려면 [`strictTemplates`](tools/cli/template-typecheck#strict-mode)를 활성화해야 합니다.
`numericCssPropertyRequiresUnit`은 `strictTemplates` 외에 다른 설정을 요구하지 않습니다.

<!--
## What if I can't avoid this?
-->

<a id="what-if-i-cant-avoid-this"></a>

## 이 문제를 피할 수 없다면 어떻게 하나요?

<!--
This diagnostic can be disabled by editing the project's `tsconfig.json` file:
-->

프로젝트의 `tsconfig.json` 파일을 수정해 이 진단을 비활성화할 수 있습니다:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "numericCssPropertyRequiresUnit": "suppress"
      }
    }
  }
}
```

See [extended diagnostic configuration](extended-diagnostics#configuration) for more info.
