# `inject()` must be called from an injection context

<a id="inject-must-be-called-from-an-injection-context"></a>

# `inject()`는 주입 컨텍스트에서 호출해야 합니다

<!--
You see this error when you try to use the [`inject`](api/core/inject) function outside of the allowed [injection context](guide/di/dependency-injection-context). The injection context is available during the class creation and initialization. It is also available to functions
used with `runInInjectionContext`.
-->

허용된 [주입 컨텍스트](guide/di/dependency-injection-context) 밖에서 [`inject`](api/core/inject) 함수를 사용하려고 하면 이 오류가 발생합니다. 주입 컨텍스트는 클래스를 생성하고 초기화하는 동안 사용할 수 있습니다.
`runInInjectionContext`와 함께 사용하는 함수에서도 사용할 수 있습니다.

<!--
In practice the `inject()` calls are allowed in a constructor, a constructor parameter and a field initializer:
-->

실제로 `inject()`는 생성자, 생성자 매개변수, 필드 초기화 코드에서 호출할 수 있습니다.

<!--
```typescript
@Service()
export class Car {
  radio: Radio | undefined;

  // OK: field initializer
  spareTyre = inject(Tyre);

  constructor() {
    // OK: constructor body
    this.radio = inject(Radio);
  }
}
```
-->

```typescript
@Service()
export class Car {
  radio: Radio | undefined;

  // 정상: 필드 초기화 코드
  spareTyre = inject(Tyre);

  constructor() {
    // 정상: 생성자 본문
    this.radio = inject(Radio);
  }
}
```

<!--
It is also legal to call [`inject`](api/core/inject) from a provider's factory:
-->

프로바이더의 팩토리에서도 [`inject`](api/core/inject)를 호출할 수 있습니다.

<!--
```typescript
providers: [
  {
    provide: Car,
    useFactory: () => {
      // OK: a class factory
      const engine = inject(Engine);
      return new Car(engine);
    },
  },
];
```
-->

```typescript
providers: [
  {
    provide: Car,
    useFactory: () => {
      // 정상: 클래스 팩토리
      const engine = inject(Engine);
      return new Car(engine);
    },
  },
];
```

<!--
Calls to the [`inject`](api/core/inject) function outside of the class creation or `runInInjectionContext` will result in error. Most notably, calls to `inject()` are disallowed after a class instance was created, in methods (including lifecycle hooks):
-->

클래스 생성 과정이나 `runInInjectionContext` 밖에서 [`inject`](api/core/inject) 함수를 호출하면 오류가 발생합니다. 특히 클래스 인스턴스가 생성된 이후에는 라이프싸이클 후킹 함수를 포함한 메서드에서 `inject()`를 호출할 수 없습니다.

<!--
```typescript
@Component({ ... })
export class Car {
  ngOnInit() {
    // ERROR: too late, the component instance was already created
    const engine = inject(Engine);
    engine.start();
  }
}
```
-->

```typescript
@Component({ ... })
export class Car {
  ngOnInit() {
    // 오류: 컴포넌트 인스턴스가 이미 생성되어 호출 시점이 너무 늦습니다.
    const engine = inject(Engine);
    engine.start();
  }
}
```

<!--
## Debugging the error
-->

<a id="debugging-the-error"></a>

## 오류 디버깅

<!--
Work backwards from the stack trace of the error to identify a place where the disallowed call to `inject()` is located.
-->

오류의 스택 트레이스를 거슬러 올라가며 허용되지 않은 `inject()` 호출의 위치를 찾으세요.

<!--
To fix the error move the [`inject`](api/core/inject) call to an allowed place (usually a class constructor or a field initializer).
-->

오류를 해결하려면 [`inject`](api/core/inject) 호출을 허용된 위치로 옮기세요. 보통 클래스 생성자나 필드 초기화 코드로 옮기면 됩니다.

<!--
NOTE: If you are running in a test context, `TestBed.runInInjectionContext` will enable `inject()` to succeed.
-->

NOTE: 테스트 컨텍스트에서 실행하는 경우 `TestBed.runInInjectionContext`를 사용하면 `inject()`를 정상적으로 호출할 수 있습니다.

```typescript
TestBed.runInInjectionContext(() => {
  // ...
});
```
