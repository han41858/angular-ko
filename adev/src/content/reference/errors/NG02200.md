# 반복 가능한 값의 변경 감지기 누락

<!--
`NgFor` could not find an iterable differ for the value passed in. Make sure it's an iterable, like an `Array`.
-->

`NgFor`가 전달된 값에 맞는 반복 가능한 값의 변경 감지기를 찾지 못했습니다. 값이 `Array`처럼 반복 가능한지 확인하세요.

<!--
## Debugging the error
-->

<a id="debugging-the-error"></a>

## 오류 디버깅

<!--
When using ngFor in a template, you must use some type of Iterable, like `Array` or `Set`.
If you're trying to iterate over the keys in an object or the entries of a `Map`, you should look at the [KeyValue pipe](/api/common/KeyValuePipe) instead.
-->

템플릿에서 ngFor를 사용할 때는 `Array`나 `Set` 같은 반복 가능한 타입을 사용해야 합니다.
객체의 키나 `Map`의 항목을 순회하려면 [KeyValue 파이프](/api/common/KeyValuePipe)를 참고하세요.
