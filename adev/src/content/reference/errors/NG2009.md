# 유효하지 않은 Shadow DOM 셀렉터

<!--
The selector of a component using `ViewEncapsulation.ShadowDom` doesn't match the custom element tag name requirements.
-->

`ViewEncapsulation.ShadowDom`을 사용하는 컴포넌트의 셀렉터가 커스텀 엘리먼트 태그 이름의 조건에 맞지 않습니다.

<!--
In order for a tag name to be considered a valid custom element name, it has to:
-->

유효한 커스텀 엘리먼트 이름으로 인정되는 태그 이름은 다음 조건을 충족해야 합니다.

<!--
- Be in lower case.
- Contain a hyphen.
- Start with a letter \(a-z\).
-->

- 소문자여야 합니다.
- 하이픈을 포함해야 합니다.
- 영문자(a-z)로 시작해야 합니다.

<!--
## Debugging the error
-->

<a id="debugging-the-error"></a>

## 오류 디버깅

<!--
Rename your component's selector so that it matches the requirements.
-->

조건에 맞도록 컴포넌트 셀렉터의 이름을 바꾸세요.

<!--
**Before:**
-->

**변경 전:**

```ts
@Component({
  selector: 'comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})

```

<!--
**After:**
-->

**변경 후:**

```ts
@Component({
  selector: 'app-comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})
```
