# 루트 엘리먼트를 찾을 수 없음

<!--
Bootstrapped components are defined in the `bootstrap` property of an `@NgModule` decorator or as the first parameter of `bootstrapApplication` for standalone components.
-->

부트스트랩할 컴포넌트는 `@NgModule` 데코레이터의 `bootstrap` 프로퍼티에 정의합니다. 독립형 컴포넌트는 `bootstrapApplication`의 첫 번째 매개변수로 지정합니다.

<!--
This error happens when Angular tries to bootstrap one of these components but cannot find its corresponding node in the DOM.
-->

Angular가 이 컴포넌트 중 하나를 부트스트랩하려고 하지만 DOM에서 해당 노드를 찾을 수 없으면 이 오류가 발생합니다.

## 오류 디버깅

<!--
This issue occurs when the selector mismatches the tag
-->

셀렉터가 태그와 일치하지 않을 때 이 문제가 발생합니다.

```typescript
@Component({
  selector: 'my-app',
  ...
})
export class App {}
```

<!-- Doesn't match the selector -->

<!-- prettier-ignore -->
```html
<html>
  <app-root></app-root> <!-- 셀렉터와 일치하지 않습니다. -->
</html>
```

<!--
Replace the tag with the correct one:
-->

올바른 태그로 바꾸세요.

<!-- OK -->

<!-- prettier-ignore -->
```html
<html>
  <my-app></my-app> <!-- 정상 -->
</html>
```
