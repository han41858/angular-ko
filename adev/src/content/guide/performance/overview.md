<docs-decorative-header title="서버 측 렌더링과 하이브리드 렌더링" imgSrc="adev/src/assets/images/overview.svg"> <!-- markdownlint-disable-line -->
다양한 렌더링 전략으로 애플리케이션 성능을 최적화하는 방법을 알아봅니다.
</docs-decorative-header>

애플리케이션의 성능을 최대한 높이는 것은 모든 개발자의 중요한 우선순위 중 하나입니다.
이 가이드는 다양한 렌더링 전략을 활용해 성능이 뛰어난 애플리케이션을 만드는 모범 사례를 따를 수 있도록 돕습니다.

| 가이드 유형                                         | 설명                                                                                                                                                                               |
| :-------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [서버 렌더링과 하이브리드 렌더링](/guide/ssr)       | 서버에서 페이지를 렌더링해 로딩 시간을 줄이는 방법을 알아봅니다.                                                                                                                   |
| [하이드레이션](/guide/hydration)                    | 서버 측 렌더링 후 애플리케이션 상태를 복원하고 기존 DOM 구조를 최대한 재사용해 애플리케이션 성능을 개선하는 과정입니다.                                                            |
| [점진적 하이드레이션](/guide/incremental-hydration) | 점진적 하이드레이션은 애플리케이션의 일부 영역을 하이드레이션되지 않은 상태로 두고, 필요해질 때 해당 영역의 하이드레이션을 점진적으로 실행할 수 있는 고급 하이드레이션 방식입니다. |
